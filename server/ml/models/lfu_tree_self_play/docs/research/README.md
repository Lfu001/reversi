# 研究計画

木状自己対戦が通常の独立自己対戦より少ない計算量で強くなれるかを調べる計画です。仮説、数理、比較条件、数値の採用理由と主張の範囲は、[実験計画（日本語）](experiment-plan.md) / [Experimental plan (English)](experiment-plan.en.md) にまとめています。日本語版を編集上の正本とし、変更時は英語版も同期します。

## 読みたい内容から探す

| 内容 | 実験計画の参照先 |
| --- | --- |
| 研究の問い、H1〜H3、従来手法との関係 | [研究の問いと主張の範囲](experiment-plan.md#1-研究の問いと主張の範囲) |
| 分岐する位置・幅、終局までの生成規則 | [最小の木状データ生成](experiment-plan.md#3-最小の木状データ生成) |
| 終局結果の集約、兄弟比較、loss と経路重み | [勝敗の集約と学習目的](experiment-plan.md#4-勝敗の集約と学習目的) |
| A/B/C/D の違いと比較条件 | [比較実験](experiment-plan.md#5-比較実験) |
| 計算コスト、棋力、評価間隔、統計上の判断 | [計算量・棋力・統計](experiment-plan.md#6-計算量棋力統計) |
| 実験の進め方と中止基準 | [段階的な実行と中止基準](experiment-plan.md#7-段階的な実行と中止基準) |

計画は実験の有効性を示す結果ではなく、未実装の工程も含みます。現在の機能を動かす場合は [パッケージの README](../../README.md)、実装の依存関係や合格条件を調べる場合は [開発計画](../development/README.md) を参照してください。
