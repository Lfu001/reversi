# M8：結果依存の拡張

[← M7](07-alphazero.md) · [一覧](../README.md) · [検証ゲート](../verification-gates.md) · [次：M9](09-reproducibility.md)

基礎実験の結果を固定した後、一度に一要因だけを変更します。全タスクを一覧へ含めますが、複数の拡張を同じrunで評価しません。

## T46 適応的分岐

- 依存：T39
- 領域：分岐予算配分、選択バイアス
- 成果：固定scheduleを対照として、事前定義した不確実性基準で枝を追加できる。
- 合格：追加条件以外を固定し、選択確率、補正方法、計算コストを記録する。

## T47 過去モデルを含む相手プール

- 依存：T39
- 領域：収集相手、モデル世代構成
- 成果：対戦相手の選択規則と世代比率を固定した相手プールを実験条件として追加できる。
- 合格：自己対戦のみの基礎条件と混ぜず、対戦構成ごとのデータと結果を追跡する。

## T48 同一根の複数木正規化

- 依存：T21、T39
- 領域：原論文に近い複数木比較
- 成果：同一根から独立に生成した複数木を明示的な群として扱える。
- 合格：基礎の兄弟leave-one-outと別のadvantage定義として実装・評価し、異なる盤面や手番を暗黙に混ぜない。

## T49 URMモデル比較

- 依存：T39
- 領域：モデルアーキテクチャ
- 成果：共通policy/valueインターフェース上でURMを独立条件として学習・評価できる。
- 合格：ResNet対照とoptimizer、予算、評価条件を揃え、モデル固有の反復回数と計算量を記録する。

## T50 optimizer比較

- 依存：T39
- 領域：AdamW、Muonその他の候補
- 成果：固定モデル上でoptimizerだけを変更した比較を実行できる。
- 合格：パラメータ分類、scheduler、学習率調整予算を明示し、モデル変更と同時に比較しない。

## T51 Batch MCTSヒューリスティクス比較

- 依存：T42、T45
- 領域：Virtual Mean、Last Iteration、Second Move、FPU
- 成果：Dの正しい基準実装へ各ヒューリスティクスを個別に追加できる。
- 合格：各要因のablation、参照版との意味差、推論速度、棋力を別々に測定する。

## 完了条件

実施した拡張ごとに独立した設定、seed、原結果、基礎条件との差分が保存され、[G7](../verification-gates.md#g7拡張研究)を満たしていること。
