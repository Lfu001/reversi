# M9：再現と報告

[← M8](08-extensions.md) · [一覧](../README.md) · [検証ゲート](../verification-gates.md)

保存済みmanifestから代表runと図表を再生成し、仮説ごとに主張できる範囲を固定します。

## T52 manifestからの代表run再現

- 依存：T39、T45、実施したM8タスク
- 領域：クリーン再実行、成果物検証
- 成果：空の出力先から代表runのdataset、checkpoint、評価結果を再生成できる。
- 合格：[G8](../verification-gates.md#g8再現性確認)を通過し、環境差による非決定性がある場合は範囲と影響を記録する。

## T53 原結果からの表・図の再生成

- 依存：T27、T39、T45、実施したM8タスク
- 領域：集計pipeline、研究成果物
- 成果：保存済み原結果から学習曲線、コスト内訳、到達率、区間、ablation表を再生成できる。
- 合格：手編集した数値を含まず、図表からrunと入力checksumへ追跡できる。

## T54 仮説別の成功・不成立・限界の報告

- 依存：T52、T53
- 領域：研究報告、主張範囲
- 成果：H1、H2、H3、Dとの比較、各拡張を分離して記述した最終報告を作る。
- 合格：否定的結果、未到達、広い区間、計画逸脱を含め、実験計画で許可されていない一般化を主張しない。

## 完了条件

G8を通過し、READMEに記載した全体完了条件を満たすこと。未実施の拡張は未実施として明示し、基礎実験の結論と混同しません。
