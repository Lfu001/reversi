# M2：A/B/Cデータ収集

[← M1](01-data-storage.md) · [一覧](../README.md) · [実行モデル](../execution-model.md) · [次：M3](03-learning.md)

Aの独立対局とB/Cの木状収集を、同じモデル・根局面・計測基盤の上に構築します。

## T11 合法手マスク付きπ_old sampler

- 依存：T02、T03、T04
- 領域：確率的行動抽出、log probability
- 成果：温度1の固定方策から復元抽出し、使用した合法手マスクとlog probabilityを保存する。
- 合格：非合法手を選ばず、頻度試験が方策確率と整合し、同じ手の重複抽出を保持する。

## T12 根局面生成とtrain・tuning・final分割

- 依存：T02、T03
- 領域：開始局面、seed registry、重複検査
- 成果：初期盤面から0〜8手の合法なランダム着手で根局面を作り、用途別集合を固定できる。
- 合格：盤面、手番、対称性を考慮した重複検査を通り、用途間の意図しない共有がない。

## T13 一様・層化・固定の分岐位置schedule

- 依存：T02、T03
- 領域：分岐位置抽選、予定と実行の記録
- 成果：分岐なし、1段、2段と、一様、3区間層化、位置20・40固定を表現できる。
- 合格：H=0、H=1、候補範囲外、早期終局、パスを含む再現性試験に合格し、未到達分岐を補充しない。

## T14 Aの独立自己対戦collector

- 依存：T06、T08、T11、T12
- 領域：独立終局経路、収集コスト
- 成果：π_old同士の独立対局を終局まで生成し、B/Cと同じ意味の辺データと計測値を保存する。
- 合格：同じ根から複数経路を作る場合の重み付けを含め、全経路が終局し、収集中のモデル更新がない。

## T15 B/C共通の木状collector

- 依存：T06、T07、T08、T11、T12、T13
- 領域：浅い分岐木、最大16終局
- 成果：木ごとに事前抽選した位置で幅4・最大2段に分岐し、全枝を実際の終局まで進める。
- 合格：位置抽選と行動抽出のRNGが分離され、同一手の兄弟を潰さず、予定分岐数と実行分岐数を記録する。

## T16 複数木のbatch inference scheduler

- 依存：T14、T15
- 領域：推論batch、待機、同時木数
- 成果：AとB/Cへ同等のbatch化機会とメモリ上限を与え、複数の進行中単位をまとめて推論できる。
- 合格：逐次参照実行と生成結果が固定seedで一致し、batchサイズ分布と待機時間を記録する。

## T17 共有あり・再計算の同一性とH1計測

- 依存：T14、T15、T16
- 領域：共通経路の共有、再生、性能計測
- 成果：同じ乱数結果と木を、共有方式と共有経路再計算方式で生成できる。
- 合格：出力データと学習上の重みが一致し、生成時間、推論件数、環境遷移数、メモリだけを比較できる。

## 完了条件

A/B/Cの収集データがG1を通過し、H1のコスト差を棋力差と混同せず測定できること。
