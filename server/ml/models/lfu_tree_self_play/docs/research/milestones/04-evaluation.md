# M4：評価と統計

[← M3](03-learning.md) · [一覧](../README.md) · [研究設計](../research-design.md) · [次：M5](05-pilot.md)

モデル選択に使う評価と、最終的な主張に使う評価を分離し、未到達seedを含めて集計します。

## T23 random・greedy・mobility・凍結モデルagent

- 依存：T03、T04
- 領域：評価相手、固定version
- 成果：決定規則と乱数seedが固定された評価相手群を構成できる。
- 合格：各agentの着手が合法で再現可能であり、凍結モデルのchecksumを結果へ記録する。

## T24 重複・対称性を検査した開始局面registry

- 依存：T02、T03、T12
- 領域：評価用開始局面、用途分離
- 成果：調整用と最終評価用の開始局面をversion付きで固定できる。
- 合格：盤面・手番・対称性を含む重複検査と、用途間アクセス制御を自動化する。

## T25 先後ペアarenaとscore計算

- 依存：T23、T24
- 領域：対局実行、ペア結果
- 成果：同じ開始局面から先後を入れ替え、勝ち1・引き分け0.5・負け0でscoreを計算できる。
- 合格：相手別結果とペアIDを保存し、中断後に未完了ペアだけを再実行できる。

## T26 探索なし評価と時間制約付き評価

- 依存：T25
- 領域：一次評価、実用評価
- 成果：方策のみの棋力と、同一対戦時間予算を与えた探索込み棋力を別の結果系列として扱える。
- 合格：全群で選択方法と時間計測の定義が一致し、二つの評価を混ぜて集計しない。

## T27 到達率、制限付き時間、曲線面積、区間推定

- 依存：T25、T26
- 領域：統計集計、seed間不確実性
- 成果：到達率、全seedのmin(検出到達時間,T)平均、同予算score、曲線面積と95%区間を計算できる。
- 合格：未到達seedを除外せず、開始局面ペアの依存を保持し、相手別結果も出力する。

## T28 調整用・最終評価用データの隔離試験

- 依存：T09、T24、T27
- 領域：モデル選択、アクセス制御、監査
- 成果：最終評価結果をbest model選択や設定変更へ使用できない実行境界を設ける。
- 合格：最終評価用IDを調整runへ渡した場合に実行を拒否し、全アクセスをmanifestへ記録する。

## 完了条件

固定された開始局面ペアで評価でき、調整用と最終評価用が混ざらず、計画で定めた統計量を原結果から再生成できること。
