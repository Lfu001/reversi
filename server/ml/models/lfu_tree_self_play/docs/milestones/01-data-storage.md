# M1：データモデルと永続化

[← M0](00-foundation.md) · [一覧](../README.md) · [検証ゲート](../verification-gates.md) · [次：M2](02-collection.md)

対局・木・学習状態を追跡できる保存基盤を作ります。部分データや二重消費を後工程へ渡さないことが中心です。

## T06 木・ノード・辺・兄弟群・コストのrecord schema

- 依存：T02、T03
- 領域：収集データの意味モデル
- 成果：親子関係、局面、手番、行動、旧log probability、旧value、モデル世代、分岐構成、乱数情報、終局結果、計算コストを表現できる。
- 合格：Aの独立対局とB/Cの木を同じ検証器で扱え、不正な親子関係やモデル世代混在を拒否する。

## T07 終局リターン集約と経路重み

- 依存：T05、T06
- 領域：教師生成、木の集約
- 成果：黒視点を保った再帰的な条件付き平均と、分岐幅に応じた経路重みを計算できる。
- 合格：早期終局、子孫数の違い、同一行動の重複標本を含む手計算例と一致する。

## T08 完了単位のatomic dataset store

- 依存：T06、T07
- 領域：datasetの追記、公開、検証
- 成果：完了した対局または木を一時領域からatomicに公開し、部分書込みを不可視にできる。
- 合格：保存・読込のround-trip、checksum、不完全データの隔離、並行読込を検証できる。

## T09 checkpoint・manifest・消費位置の整合保存

- 依存：T02、T08
- 領域：モデル世代、optimizer、RNG、処理段階
- 成果：モデルとデータ消費位置を同じmanifestで確定し、未確定更新を消費済みにしない。
- 合格：checkpoint、設定ハッシュ、dataset範囲の不一致を検出し、直前の確定状態へ戻れる。

## T10 強制停止・再開・重複防止試験

- 依存：T08、T09
- 領域：障害注入、idempotency
- 成果：収集、公開、学習、checkpoint確定、評価の各境界へ停止を注入できる。
- 合格：全境界で再開後の欠落、二重学習、二重評価、モデル世代混在がない。

## 完了条件

T06〜T10の保存基盤を使って[G1](../verification-gates.md#g1データ生成と永続化)を検証できること。G1通過前に実データをtrainerへ接続しません。
