# M5：実行制御とPilot

[← M4](04-evaluation.md) · [一覧](../README.md) · [実行モデル](../execution-model.md) · [次：M6](06-abc-study.md)

個別機能を再開可能な一つの実験系へ接続し、本実験で固定する値を実測から決めます。

## T29 収集・学習・評価のCLIとorchestrator

- 依存：T10、T17、T20、T25
- 領域：段階実行、run状態
- 成果：各段階を個別実行でき、orchestratorが確定成果物だけを次段へ渡す。
- 合格：段階単独実行、一巡実行、再開、dry-run、設定不一致拒否を検証できる。

## T30 安全な更新境界と0.1T評価schedule

- 依存：T09、T29
- 領域：予算管理、保存、評価予約
- 成果：累積収集・学習時間が0.1T刻みに達した後の最初の安全な境界でcheckpointと評価を確定する。
- 合格：予算超過分を実時間へ含め、進行中の木やoptimizer stepを途中打切りしない。

## T31 計算時間、推論数、メモリ、待機時間の計測

- 依存：T16、T20、T29
- 領域：profiling、研究指標
- 成果：収集、学習、永続化、評価の時間、推論盤面数、学習sample数、RSS、デバイスpeak、待機時間、保存量を分離して記録する。
- 合格：異種処理を単一の推論数へ合算せず、各値をrunとモデル世代へ関連付ける。

## T32 G2最小End-to-End smoke run

- 依存：T29、T30、T31
- 領域：A/B/Cの極小実行
- 成果：小型設定で収集から再開までを一巡した固定fixtureと実行記録を得る。
- 合格：[G2](../verification-gates.md#g2最小end-to-end)の全条件を自動確認し、失敗時に後続runを開始しない。

## T33 G3 A/B/C 3-seed短時間比較

- 依存：T21、T22、T27、T32
- 領域：学習信号の初期比較
- 成果：同じ短時間予算でA/B/Cを3 seed実行し、更新挙動と評価結果を得る。
- 合格：[G3](../verification-gates.md#g3学習信号の小規模比較)の全指標を黒・白別および群別に出力し、random勝利を研究成功判定に使用しない。

## T34 batch、同時木数、収集規模、評価局数のPilot

- 依存：T31、T33
- 領域：性能、分散、実行可能性
- 成果：利用マシン上の実測から本実験候補値を比較できる。
- 合格：候補ごとの時間、メモリ、評価分散、未到達率を残し、採用理由を記録する。

## T35 本実験設定の凍結と検証コマンド

- 依存：T34
- 領域：事前固定、設定監査
- 成果：モデル、AdamW、収集量、T、分岐条件、seed、相手、開始局面、評価局数、到達閾値、統計手続きを固定する。
- 合格：[G4](../verification-gates.md#g4pilotと設定凍結)を満たす設定、ハッシュ、入力checksum、検証結果を一つのmanifestへまとめる。

## 完了条件

G2とG3を通過し、G4の凍結manifestが作成されていること。凍結後の変更は新しいexperiment IDとして扱います。
