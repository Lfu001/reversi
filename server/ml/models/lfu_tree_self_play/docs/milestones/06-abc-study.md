# M6：A/B/C本実験

[← M5](05-pilot.md) · [一覧](../README.md) · [検証ゲート](../verification-gates.md) · [次：M7](07-alphazero.md)

凍結設定を変更せず、主対照A、木状収集B、提案法Cを比較してH1〜H3を個別に判断します。

## T36 A/B/Cを5 seed以上で実行

- 依存：T35
- 領域：本学習、進捗監視、障害復旧
- 成果：凍結設定のA/B/Cについて全seedの完了runまたは明示的な未到達結果を得る。
- 合格：設定変更なしで同一総予算を適用し、失敗・再開履歴と予算超過を含めて保存する。

## T37 分岐なし・1段・2段アブレーション

- 依存：T35、T36
- 領域：分岐段数、相関、共有率
- 成果：幅と他条件を揃えた分岐段数別の結果を得る。
- 合格：実行分岐数、終局数、共有率、実コスト、更新分布を段数別に報告する。

## T38 一様・層化・固定位置アブレーション

- 依存：T35、T36
- 領域：位置選択、局面段階の偏り
- 成果：段数と幅を揃えた位置選択規則別の結果を得る。
- 合格：手数帯、手番、合法手数ごとの予定・実行分岐数と更新量を報告し、未到達分岐を補充しない。

## T39 H1・H2・H3の個別集計と判断

- 依存：T17、T27、T36、T37、T38
- 領域：仮説判定、結果固定
- 成果：共有コスト、兄弟比較の追加効果、目標棋力への総コストを別々に結論づける。
- 合格：到達率低下の有無、20%以上の時間短縮点推定、95%区間、同予算結果を計画どおり報告し、未確認を成功扱いしない。

## 完了条件

[G5](../verification-gates.md#g5abc本実験)を満たし、H1、H2、H3の結果が成功、不成立、未確認のいずれかとして固定されていること。
